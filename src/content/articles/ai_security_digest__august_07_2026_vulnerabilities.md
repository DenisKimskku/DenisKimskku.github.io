## Den's Take

The industry disclosure of shared exploit incidents across major labs, while alarming, reads less like a fundamental architectural failure and more like a persistent failure in operational security hygiene. The fact that three in four AI-generated patches introduce regressions confirms that the process of automated security remediation is inherently leaky, regardless of the underlying model's capabilities. The discussion tends to frame this as a "vulnerability" in the model itself, when it's often a vulnerability in the *pipeline* surrounding the model. Furthermore, the emphasis on defensive layers, like OpenAI’s reported "Rotten to the core" defense, misses the point: if the entry points—the prompts, the context, the data flow—are not structurally constrained, no amount of internal model hardening will suffice. prior work on agent vulnerabilities showed how complex interactions create attack surfaces that simple component-level fixes cannot address. prior work argued that security focus must expand beyond individual model components to encompass entire complex, interacting AI systems.
