# Artifact-Mediated Propagation Across Isolated LLM Agents

## TLDR
*   **What**: Adversarial state spreads across independent assistants via shared artifacts.
*   **Who's at risk**: Stateful personal LLM assistants used in human workflows.
*   **Key number**: In larger simulated environments, even GPT-5.6 Luna exhibits substantial spread, reaching 60–80% of agents with propagation chains extending to eight hops.

## The Artifact–Memory–Artifact Cycle

Modern LLM assistants are increasingly stateful; they maintain persistent memory across sessions and operate over persistent artifacts like reports and documents. While existing research has looked at how malicious content persists in a *single* assistant’s memory, this paper focuses on a different failure mode: cross-agent propagation. The gap addressed here is that most prior work examines single-agent compromise or propagation within tightly coupled agent networks. This paper introduces artifact-mediated propagation, which describes how an attack moves between assistants that have no direct communication channel. The attack is seeded in one artifact, stored in Assistant A’s memory, reproduced into a second artifact, and then consumed by Assistant B. This cycle—artifact $\to$ memory $\to$ artifact $\to$ memory—allows an adversarial state to survive beyond the scope of a single interaction and spread across otherwise isolated agents, driven purely by human-mediated artifact exchange.

## Endpoint-Assisted Propagation

The core insight enabling multi-hop spread is the shift from relying on the agent to perfectly reproduce the entire attack prompt, which is inherently lossy, to leveraging an external service. Instead of forcing each infected agent to perfectly retain and rewrite the full adversarial prompt $P_{\phi}(g)$, the attack is designed to encourage the agent to use an external endpoint. In this endpoint-assisted design, the agent only needs to successfully retain the adversarial goal ($g$), the instruction to store it, and the instruction to call the external service. The adversary controls this service, which canonicalizes and reinserts a fresh, uncorrupted copy of the attack prompt into any artifact the agent sends it. This breaks the degradation chain. A successful transmission follows the pattern: $P_{\phi}(g) \to M_a \to \text{Endpoint}(d') \to M_b$, where $M_a$ and $M_b$ are the private memories of successive agents and $d'$ is an artifact created during a routine task.

## Propagation Depth via Goal-Agnostic Templates

The mechanism for achieving broad spread relies on optimizing a goal-agnostic attack template, $P_{\phi}(g)$, before deployment. The attacker optimizes the goal-agnostic instructions, $\phi$, using agent-driven red teaming across development universes $D_{\text{dev}} = \{(U_i, g_i)\}_{i=1}^{N_{\text{dev}}}$. The objective is to find $\phi$ that maximizes multi-hop propagation. The search process involves an AI agent proposing revisions to $\phi$, running tests on search universes, and diagnosing failures (e.g., an agent failing to call the endpoint). The template is frozen once it achieves second-hop survival on both search and validation universes. The resulting attack prompt $P_{\phi^{\star}}(g_{\text{test}})$ is then evaluated on unseen goals and workflows. The paper demonstrates that this framework can cause attacks to propagate across many independently operated assistants with no direct communication.

## Limitations

The model assumes assistants possess outbound network access to external services, which is argued to be common for agents interfacing with user services, though this remains an assumption. The attack relies on the agent retaining the core goal ($g$) and the endpoint instruction, rather than the full prompt, which could fail if an agent drops one of these instructions during a writing task. The study focuses on artifact-mediated transfer between independent users, excluding scenarios involving shared, collaborative state or direct LLM-to-LLM messaging.

## What practitioners should do

*   Audit the external service endpoints used by personal AI assistants to ensure they do not possess write access to artifacts being generated by the assistant.
*   Assume that any artifact produced by an assistant could potentially carry an adversarial state if the assistant has been previously exposed to a poisoned seed.
*   Monitor for unusual outbound network activity from stateful agents, as this is the mechanism enabling the propagation step.
*   Recognize that even if an agent appears to be performing a benign task, its memory state might contain instructions designed to facilitate future, unrelated infections.

## Verdict

Read for ML engineers and security researchers interested in agentic persistence and supply chain risks. It provides a concrete, novel model for how adversarial state can move through ostensibly isolated, human-managed workflows.

---

## Den's Take

The paper presents a compelling model for state persistence across agent boundaries, shifting the focus from prompt injection to artifact contamination. However, the reliance on the agent retaining only the core goal ($g$) and the endpoint instruction feels like a weak point in the attack chain. If an agent is compromised to the point where it cannot reliably execute a simple instruction—like calling a specific external service—the entire multi-hop mechanism collapses. The success hinges on a very specific, high-level instruction retention, which might be less robust than the authors imply.
