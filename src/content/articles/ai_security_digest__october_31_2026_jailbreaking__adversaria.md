22% is the metric reported by Meta AI and CMU Researchers regarding the reduction in AI jailbreak rates using pre-deployment training data filters.

## Paper Highlights
[Surprise Masking: Private Data Filtering with Model Likelihoods](/writing/surprise_masking_private_data_filtering_with_model_likelihoo) — Uses reference model perplexity to identify and mask private data spans in fine-tuned LLMs. Practitioners should examine this as it addresses data leakage risks inherent in model customization.
[Beyond RTT: An Adversarially Robust Two-Tiered Approach For Residential Proxy Detection](/writing/beyond_rtt_an_adversarially_robust_twotiered_approach_for_re) — Introduces a novel feature extraction and CorrTransform method for identifying residential proxies, achieving over 92% F1. This offers technical insight for content providers and ISPs monitoring IP usage.
[Achieving Interpretable DL-based Web Attack Detection through Malicious Payload Localization](/writing/achieving_interpretable_dlbased_web_attack_detection_through) — WebSpotter accurately pinpoints the exact locations of malicious payloads within HTTP requests. Operators using complex, uninterpretable Deep Learning Web attack detectors can benefit from this localization capability.

## Den's Take

The reported 22% reduction in jailbreak rates via pre-deployment training data filters feels like a statistical rounding error designed to placate regulators. These filters only address the known training set weaknesses; they do nothing to stop novel prompt engineering or the systemic flaws in context handling that allow for circumvention. The focus on filtering data—as seen in the work on private data masking—misses the more fundamental problem: the inherent fragility of the instruction-following mechanism itself. If the system's security relies on maintaining a specific, hardcoded conversational state, then any adversarial input that successfully shifts that state, regardless of its origin, is a win for the attacker. I previously argued that LLM security vulnerabilities stem from fundamental tokenization and context management flaws, not just psychological framing [AI Security Digest — October 29, 2026: Jailbreaking & AI Agents](/writing/ai_security_digest__october_29_2026_jailbreaking__ai_agents). Relying on these training filters is just treating symptoms while the core architecture remains exploitable.
