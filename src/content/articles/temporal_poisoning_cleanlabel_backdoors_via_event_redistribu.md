# Temporal Poisoning: Clean-Label Backdoors via Event Redistribution in Spiking Neural Networks

As neuromorphic hardware and Spiking Neural Networks (SNNs) transition into real-world deployments—powering safety-critical edge platforms like autonomous driving systems and low-latency robotics using chips like Loihi—their unique temporal processing characteristics introduce novel security risks. While deep learning pipelines have long guarded against spatial backdoor injections, SNNs rely on the precise timing of spikes rather than just their aggregate count. A new study reveals that this temporal dimension creates an entirely invisible attack vector, allowing adversaries to manipulate model behavior without changing a single pixel's total event count or modifying any training labels.

| | |
|---|---|
| **Attacker** | Clean-label data poisoner with digital access to the training event streams; cannot alter labels, model architecture, loss functions, or training weights. |
| **Victim** | SNN-based systems (using convolutional or transformer architectures like SpikformerLite) trained on neuromorphic event data from Dynamic Vision Sensor (DVS) cameras. |
| **Goal** | Force the SNN to predict an attacker-selected target class ($y_t = 0$) at test time when the temporal trigger is present, while maintaining normal accuracy on clean inputs. |
| **Budget** | A small poison rate ($\rho$ between 0.01 and 0.10 for N-MNIST/CIFAR10-DVS, and up to 0.50 for DVS-Gesture) applied only to the target-class training pool. |

## Background / Problem Setup

To understand how temporal poisoning operates, we must first look at how SNNs process neuromorphic data. Unlike traditional frame-based cameras, DVS cameras asynchronously report per-pixel brightness changes as an event stream $\mathcal{E}$. To train SNNs, these are binned into $T$ discrete time windows, yielding a tensor $X \in \mathbb{N}^{T \times 2 \times H \times W}$. Summing this tensor over $T$ yields a spatial "rate frame" $R(\mathcal{E})$. 

Previous backdoor attacks on SNNs assumed "dirty-label" poisoning, where poisoned samples are explicitly relabeled to a target class. However, this is easily caught by manual inspection or automated relabeling. "Clean-label" attacks keep the original labels untouched, but in the image domain, they require modifying the spatial content.

The table below contrasts this temporal poisoning technique against other SNN backdoor attacks in the literature:

| Attack Method | Trigger Modality | Label Constraint | Rate Frame Invariance (SSIM) | Defender Visibility |
| :--- | :--- | :--- | :--- | :--- |
| **SNN Backdoor** (Abad et al. [1]) | Spatial (static/moving squares) | Dirty-label (Mislabeled) | < 1.00 (Modified pixels) | High (Detected by visual inspection/relabeling) |
| **Sneaky Spikes** (Abad et al. [2]) | Spatio-temporal triggers | Dirty-label (Mislabeled) | < 1.00 (Modified pixels/polarity) | High (Caught via label-check / visualization) |
| **Flashy Backdoor** (Riaño et al. [27]) | Physical light flashes (DVS sensor) | Dirty-label (Mislabeled) | < 1.00 (Significant spatial artifacts) | High (Visible scene alteration) |
| **Temporal Poisoning** (Riaño et al.) | Temporal-only timestamp remapping | Clean-label (Correct labels) | **1.00 (Mathematically identical)** | **Zero** to any rate-collapsed or spatial checks |

## Methodology

The core of the attack lies in remapping event timestamps without adding, removing, or spatially relocating a single event. The temporal trigger is a function $\phi(t)$ that replaces the original timestamp $t_i$ for each event $e_i = (x_i, y_i, t_i, p_i)$ in a stream. This leaves the spatial rate frame $R(\mathcal{E})$ completely untouched, achieving an exact SSIM of 1.00 (as evaluated in Section 5.2).

As Section 4.1 describes, the paper defines three remapping families:
1. **Concentrate**: Compresses all events into a narrow temporal window of width $w \ll \Delta$ starting at $t_0$:
   $$\phi_{\text{conc}}(t) = t_0 + \frac{w}{\Delta}t$$
   This packs the stream into a brief, intense burst at a specific target bin $t^*$.
2. **Front-load**: Moves events toward the beginning of the recording using a power map with exponent $\gamma > 1$:
   $$\phi_{\text{front}}(t) = \Delta \left( \frac{t}{\Delta} \right)^\gamma$$
   This draws the event mass into the leading $k$ bins while preserving event order.
3. **Shift**: Shifts timestamps by a constant temporal offset $\delta$ with wraparound:
   $$\phi_{\text{shift}}(t) = (t + \delta) \bmod \Delta$$

During training, the attacker selects a target class $y_t$ (fixed to class 0 in the paper's main evaluation) and replaces a fraction $\rho$ of target-class training streams with their temporally transformed versions. Crucially, the labels remain $y_t$, adhering to the clean-label constraint. The network is trained using backpropagation with surrogate gradients (specifically, the ATan surrogate gradient) on SpikingJelly.

The code block below demonstrates how the `concentrate` trigger is programmatically applied to a set of neuromorphic events:

```python
import numpy as np

def apply_concentrate_trigger(events, t_star, T, delta=1.0):
    """
    Apply a temporal concentration trigger to a neuromorphic event stream.
    
    events: structured numpy array with fields (x, y, t, p)
    t_star: target bin index (0 to T-1)
    T: total number of time bins
    delta: recording duration
    """
    bin_duration = delta / T
    t0 = t_star * bin_duration
    w = bin_duration
    
    # Apply transformation to the 't' field in place
    events_poisoned = events.copy()
    events_poisoned['t'] = t0 + (w / delta) * events['t']
    return events_poisoned
```

### A Skeptical Analysis of the Results

While the ASR values are impressive, a closer look at the paper's tables reveals critical practical trade-offs:
- **Clean Utility Penalty**: On CIFAR10-DVS, successful temporal poisoning induces a severe performance penalty. Clean accuracy drops from 0.62 to 0.54 for the conv-SNN and from 0.60 to 0.46 for the SpikformerLite model (a massive 14% drop). This performance degradation is highly likely to trigger automated anomaly detection flags during deployment.
- **Trigger Sensitivity**: The `shift` trigger is a complete failure, achieving near-zero ASR in almost all configurations. This confirms that simple phase rotation without changing local event coincidence does not train a stable backdoor.
- **Defensive Blind Spots (Section 7)**: 
  - **STRIP (rate)** and **Activation Clustering** fail completely, yielding True Positive Rates (TPRs) of 0.01 (random chance) and 0.00 on concentrate across all six cells.
  - **Neural Cleanse (spatial)** is blind on conv-SNN models, with a maximum anomaly index of 0.47 (well below the flag threshold of 2.0).
  - **Spectral Signatures** works partially on convolutional SNNs (TPR = 1.00 on N-MNIST and DVS-Gesture) but completely fails (TPR = 0.00) on SpikformerLite.
  - **Pruning (Table 8)** fails to remove the backdoor; on N-MNIST, the drop in ASR is exactly 0.00, proving the backdoor utilizes the same neurons as clean classification features.

## Limitations & Open Questions

While the attack successfully bypasses rate-collapsed validation, it is not universally invisible:

1. **Visibility to Time-Aware Defenses**: As the authors demonstrate with their custom model-free "temporal-axis detector" (Section 6.4), directly analyzing the normalized per-step event mass $p[\tau]$ yields a TPR of 1.00 for the `concentrate` and `front-load` triggers. Any defender who specifically tests for time-step distribution anomalies will instantly catch this attack.
2. **Physical Feasibility**: The attack is evaluated purely in the digital domain. Although physical SNN backdoors exist (like Flashy Backdoor), reproducing precise temporal remapping in the real physical world through a physical DVS sensor remains an open and highly difficult challenge.
3. **Budget vs. Stealth Trade-off**: High-complexity datasets like CIFAR10-DVS require larger poisoning budgets and result in degraded overall performance, meaning the attack lacks stealth in complex environments.

## What Practitioners Should Do

If you are developing or deploying SNNs on neuromorphic hardware, standard spatial deep learning defenses are insufficient. Implement these time-aware mitigations instead:

1. **Reject Rate-Collapsed Defenses**: Do not use spatial-only versions of STRIP or Neural Cleanse. Ensure any pre-training data auditing pipeline retains and analyzes the temporal dimension of your neuromorphic recordings.
2. **Implement an Event-Mass Sanitizer**: Before feeding event streams to SNN training pipelines, calculate the normalized event mass $p[\tau]$ across your discretization steps $T$. Flag and quarantine any samples exhibiting extreme peak mass ($\max_\tau p[\tau]$) or anomalous Shannon entropy values compared to the dataset's running mean.
3. **Audit via Temporal Neural Cleanse**: If using reverse-engineering defenses, implement the paper's temporal Neural Cleanse variant (Section 6.3) that optimizes a per-step gain vector of length $T$, penalizing its $L_1$ distance from a flat temporal profile. Look for burst-shaped gain profiles that indicate temporal trigger injection.
4. **Track Training Cohort Deviations**: Monitor validation metrics closely during training. An unexpected drop in clean utility (e.g., a $>5\%$ reduction in test accuracy for CIFAR-like datasets) accompanied by normal training loss should trigger a complete audit of the target-class temporal distributions.

## The Takeaway

Temporal poisoning exposes a critical design blind spot in current AI security: transferring defenses from the frame-based image domain to neuromorphic SNNs ignores the temporal axis where SNNs actually compute. As these energy-efficient models find their way into edge robotics and autonomous platforms, security practitioners must transition from static, spatial-only data validation to time-aware temporal audits.

## Den's Take

While the mechanics of mathematically preserving the spatial rate frame (SSIM = 1.00) while shifting event distributions are elegant, the threat model assumes unrealistic temporal precision during physical execution. In real-world neuromorphic hardware, Dynamic Vision Sensors (DVS) are notorious for latency jitter and thermal noise. Because this backdoor relies on precise temporal remapping across $T$ discrete bins, physical-world environmental variations will likely jitter the trigger events out of their targeted temporal windows.

This vulnerability highlights a broader trend in neuromorphic security. In my previous reviews of embodied AI security, I have often noted that physical-world feedback loops in autonomous systems introduce dynamic noise that can break highly stylized digital attacks. 

If an SNN defender dynamically alters the temporal bining size $T$ at runtime—shifting from, say, 10 steps to 15 steps—the temporal trigger's alignment collapses entirely without any active defense running. Practitioners should explore dynamic temporal scaling as a lightweight, zero-overhead countermeasure before deploying SNNs on edge hardware like Loihi. The authors' clean-label bypass of spatial checks is mathematically sound, but its reliance on perfect temporal synchronization makes it incredibly fragile in the wild.
