# AI Security Digest — October 24, 2026: AI Agents & Vulnerabilities

In an AgentPhishing evaluation, the benchmark revealed that LLM email agents face significant threats from adaptive persuasion attacks. This indicates that automated agents handling sensitive data require immediate scrutiny regarding prompt injection and social engineering vectors.

## Paper Highlights
[AgentPhishing: A Benchmark of LLM Email Agents Under Adaptive Attack](/writing/agentphishing_a_benchmark_of_llm_email_agents_under_adaptive) — Justin Tan, Miao Li, Ding Zhao. This work introduces a benchmark specifically designed to test LLM email agents against adaptive phishing techniques. Practitioners should use this to stress-test agents performing delegated tasks with sensitive input.
[Data-Void Exploits in Web-Searching LLMs](/writing/datavoid_exploits_in_websearching_llms) — Michele Guerra, Wuyeh Jobe, Sanjana Nambiar. Researchers demonstrated that attackers can manipulate web-searching LLMs by seeding sparse web spaces with disinformation. This finding is pertinent as it shows how synthetic data poisoning can influence synthesized answers used by public-facing LLMs.

## Den's Take

The focus on adaptive persuasion attacks against email agents in the reviewed work is too narrow. While prompt injection is a vector, the real danger for delegated tasks isn't just convincing the agent to execute a malicious instruction; it is the agent being manipulated into generating *plausible-sounding* but fundamentally flawed output based on poisoned contextual data. When I examined defenses, I found that relying on conventional delimiters to separate instructions from data is inherently weak, as demonstrated in my CTF work [my 20-level LLM red-teaming CTF](/writing/llm_red_teaming_ctf_20_levels). The systems being tested here likely suffer from the same architectural flaw: treating conversational context as a secure boundary when it is merely a convention. The idea that simply stress-testing the input prompt is sufficient overlooks the systemic failure of the agent's internal reasoning loop.
